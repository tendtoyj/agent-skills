# agentfiles

**Claude Code를 나만의 AI 팀으로 만드는 스킬 플러그인 모음**

마케팅 리서치, 콘텐츠 제작, UX 설계, 개발 워크플로우까지 — 각 분야 실무에 바로 쓸 수 있는 Claude Code 스킬 플러그인입니다.

---

## 이런 분들을 위해 만들었어요

- **마케터** — 브랜드 보이스 정의부터 SEO 콘텐츠, 이메일 시퀀스까지 자동화하고 싶은 분
- **UX 실무자** — 리서치 설계, 페르소나, 유저플로우를 체계적으로 뽑아내고 싶은 분
- **바이브코더** — 아이디어를 프론트엔드 코드로 빠르게 구현하고 싶은 분
- **일반 직장인** — 보고서, 회의록, 발표자료 정리를 AI로 효율화하고 싶은 분
- **콘텐츠 크리에이터** — 카드뉴스, SNS 콘텐츠를 기획부터 이미지 렌더링까지 한 번에 끝내고 싶은 분

## 작동 방식

각 플러그인은 **오케스트레이터 패턴**으로 동작합니다.

```
사용자 요청 → 오케스트레이터가 현재 상태 진단 → 필요한 스킬 순서대로 실행 → 결과물 생성
```

- **공유 메모리**: 플러그인마다 메모리 디렉토리가 있어서, 이전 작업 결과를 기억하고 이어갈 수 있습니다
- **의존성 인식**: 스킬 간 선후 관계를 파악해서 최적의 순서로 안내합니다
- **멀티 모드**: 처음부터 전체 실행, 부분 재실행, 빠른 수정 등 상황에 맞는 모드를 선택할 수 있습니다

## 시작하기

### 요구사항

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) CLI 설치

### 설치

```bash
# 레포 클론
git clone https://github.com/tendtoyj/agentfiles.git

# Claude Code에서 플러그인 디렉토리를 열어 사용
cd agentfiles
```

### 사용 예시

Claude Code 실행 후, 자연어로 요청하면 관련 스킬이 자동으로 작동합니다.

```
"우리 브랜드 보이스를 정의해줘"          → vibe-mkt 실행
"경쟁사 3곳을 분석해줘"                 → mkt-study 실행
"이 내용으로 카드뉴스 만들어줘"           → card-news 실행
"유저 인터뷰 가이드를 만들어줘"           → ux-skills 실행
"이번 회의 내용 정리해줘"               → office-work 실행
```
